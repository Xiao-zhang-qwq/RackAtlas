## 一、功能定位

产品提供「一句话改数据」：运维人员用中文口语直接说要做什么，系统解析成可预览的**计划（plan）**，确认后执行，并支持整批撤销。解析分两层——本地规则引擎优先命中，未命中时由大模型兜底；两层最终产出同一种 plan，下游只认 plan，因此规则与模型可以无缝互补。

### 创新点（面向真实运维输入，而非标准书面语）

| 创新点 | 说明 |
|---|---|
| 错别字 / 口误容错 | 中文常见同音错字、字母数字混淆（`AOl` ↔ `A01`、`EO9` ↔ `E09`）、带空格的错字（`交 焕 机`）在解析前统一纠正，并记录改了哪些字供用户复核 |
| 柜名 / SN / 型号一字纠错 | 用编辑距离 1 把打错一个字符的实体对齐到库里的真实值，而不是直接报「找不到设备」 |
| U 位粘连拆分 | `A02U20` 自动拆成 `A02` + `U20`，避免把 `9U` 误当成机柜高度 |
| 口语与倒装 | 去掉客套话、语气词，处理「迁到 E09 的某某设备到 F09」这类口语倒装 |
| 混乱语句的多指令拆分 | 中文全角分号 / 逗号 / 无标点连续说话，都要拆成多条指令分别执行；全量实现是带上下文判断的三级拆分，避免把「A列 5台；B列 6台」误拆 |
| 问句不误判为写操作 | 「A01 的 SN 是多少」是查询，不是把 SN 改成别的；没有写动词时一律按只读处理 |
| 电力词条 | 机柜额定功率、设备功耗、剩余功率可作为自然语言指令的查询与修改对象 |
| 端口范围 / 列表 | 「1-8 口划到 VLAN 100」自动展开成 8 条计划，一次执行、一次整批撤销 |
| 冲突保护 | 端口已被别的设备占用时提示换端口或确认替换，不静默覆盖 |

## 二、本仓库公开了什么

| 文件 | 内容 | 性质 |
|---|---|---|
| `lib/nl-public-demo.js` | 输入归一化骨架、**编辑距离 1** 算法、问句/写动词分界正则、8 条演示级错别字映射、简化多指令拆分、只读/写入二分 | 部分代码；其中 4 处标注「逐字摘录」来自全量工程 `lib/nl.js`，其余为便于独立运行的演示级最小实现 |
| `examples/nl-demo.js` | 10 条虚构脏输入与断言，可 `node examples/nl-demo.js` 直接运行 | 可运行的能力证据；不联网、不调模型、不写数据、不执行任何变更 |

> 说明：演示输出里的 `AO1→A01` 是通用编辑距离对齐到词表的结果，不是完整的字母数字混淆规则；
> 完整工程另有专门的混淆处理与 U 位粘连拆分，均未公开。

公开片段能**实际跑通**「全角归一 → 错别字纠正 → 实体一字纠错 → 多指令拆分 → 只读/写入判定」，用于佐证上述创新确实由本项目的原创代码实现。
