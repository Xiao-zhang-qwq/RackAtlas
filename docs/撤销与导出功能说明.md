# 最近变更 · 撤销 · 导出 —— 功能说明与公开边界

> 本文对应公开仓库 `IDC3D-core` 中两个可运行证据：
> `node examples/undo-demo.js`、`node examples/export-demo.js`。
> 文中所有机房、机柜、设备、SN、IP 均为虚构示例；`192.0.2.x` 为文档保留地址段。

## 一、三条链路总览

| 功能 | 用户能感知的行为 | 公开状态 |
|---|---|---|
| 最近变更 | 首页「最近变更的设备」按更新时间倒序列出设备，并自动带出所属机柜、机房、机房编号 | 本仓库公开 `lib/undo-public-demo.js` 的 `recentDevices()` 证明子集 |
| 撤销上一步 | 任何手动修改前先保存整库快照，一键回到上一步；最多保留 20 步 | 本仓库公开内存版撤销栈证明子集 |
| Excel / JSON 导出 | 台账、机柜布局、机柜矩阵、双格式四种版式；按状态 / 客户 / 类型着色、自定义颜色、按机房范围过滤、自定义文件名 | 本仓库公开导出选项白名单解析证明子集 |

> 说明：完整实现（服务端撤销栈与 HTTP 路由、零依赖 XLSX 生成引擎、导出下载路由、导出弹窗 UI）**均不在本仓库公开**，仅由私有仓库 `IDC3D-full` 存证。

## 二、最近变更（原创设计点）

不是简单按时间排一张表，而是把设备与拓扑位置一起还原：

1. 按更新时间倒序取最近一批；
2. 用机柜 → 机房两级索引补齐机柜名、机房名、机房编号；
3. 机柜或机房已不存在的孤儿记录过滤，首页不出现悬空记录。

公开子集 `recentDevices()` 与全量实现一致：先按时间截断，再过滤孤儿。

## 三、撤销（原创设计点）

1. **整库快照而非增量反向操作**：在做任何修改之前保存全库，撤销时整体还原，不依赖「反操作」的正确性，因此新增 / 编辑 / 删除 / 下架 / 导入等异构操作都能用同一套机制回退。
2. **LIFO + 20 步上限**：后进先出，超出上限淘汰最老一步；状态接口只暴露摘要，不把整库快照外泄。

公开子集 `lib/undo-public-demo.js` 覆盖整库快照、LIFO、步数上限；原子落盘、并发写串行、完整 HTTP 路由等**未公开**。

## 四、导出（原创设计点）

1. **四种版式**：机柜布局图 / 机柜矩阵 / 设备台账 / 双格式，另有设备详细信息工作簿。
2. **白名单选项解析**：格式、着色方式非法值回退默认值；自定义颜色只接受 6 位十六进制且上限 300 条；文件名清理非法字符；按机房范围过滤。
3. **台账字段与业务模型同源**：与导入、AI、电力字段共用同一套字段定义。

公开子集 `lib/export-public-demo.js` 覆盖选项白名单解析与颜色映射校验；零依赖 OOXML 生成引擎、下载路由、导出弹窗 UI 等**未公开**。

## 五、公开边界（保证源代码安全）

**已在本仓库公开**（均为最小可运行证明子集）：

- `lib/undo-public-demo.js`：内存版撤销栈与最近变更聚合；
- `lib/export-public-demo.js`：导出选项白名单解析与颜色映射校验；
- `examples/undo-demo.js`、`examples/export-demo.js`：两个自检脚本。

**未公开，仅由私有仓库 `IDC3D-full` 存证**：

- 服务端撤销栈与 `/api/undo/*` 全部 HTTP 路由、原子落盘、写请求串行队列；
- 零依赖 XLSX 生成与解析引擎、全部导出下载路由与响应头；
- 导出弹窗 UI、二级设置面板、前端下载交互；
- 图例着色完整业务规则、超链接回跳拼接、部署侧备份 / 回滚脚本；
- 全部 HTML / CSS / 三维渲染资源与前端交互组件。

## 六、验证方式

```bash
node examples/undo-demo.js     # 整库快照 / LIFO / 20 步上限 / 最近变更 / 孤儿过滤 / 撤销联动
node examples/export-demo.js   # 选项白名单 / 颜色校验 / 范围过滤 / 导出结果渲染
```

两个脚本纯内存运行，不联网、不启动服务、不写磁盘、不使用任何真实机房数据。私有仓库 `docs/版权存证核验.md` 记录同一份公开边界声明，与本文构成双向印证。
