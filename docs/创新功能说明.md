# 核心创新功能说明（公开证明子集）

> 本文说明本仓库公开的原创逻辑在完整产品中的作用，用于佐证版权归属与功能创新。
> 文中所有机柜、设备、SN、VLAN、机房名称均为虚构示例。
> **本仓库只公开核心逻辑的最小可运行证明子集，不含任何完整实现、UI、前端交互、三维渲染或静态资源。**

## 一、设备 ↔ 网络设备接口联动（双向）

设备详情里只要填「上联交换机 SN + 端口号」，系统会自动定位交换机、生成可读位置，并点亮对应端口；反向地，设备侧信息变化会同步回端口，设备下架则只熄灭自己占用的那一个端口。

| 触发 | 联动结果 |
|---|---|
| 新增 / 编辑设备，填上联 SN 与端口 | 自动定位交换机 → 端口点亮，回填对端、线缆、VLAN |
| 端口已被另一台设备占用 | 返回冲突，不静默覆盖 |
| 只改设备所属 VLAN | VLAN 自动同步到已关联的上联端口 |
| 设备下架 | 仅熄灭本设备占用的端口，不影响同交换机其他端口 |

证明子集：`lib/linkage.js`（逐字摘录自全量工程的联动实现，仅做脱离 HTTP 层的最小等价替换）。完整调用链见 `examples/linkage-demo.js`：

```bash
node examples/linkage-demo.js
```

自检覆盖：按 SN 定位 → 端口点亮 → VLAN 同步 → 冲突保护 → 下架回退，全部断言通过。

创新点在于**以设备为入口反向维护端口拓扑**，并用「端口对端归属校验」避免误伤：不是简单覆写端口状态，而是先确认链路确实属于该设备，才允许解除或覆盖，让机柜视图、设备详情与交换机端口面板三处数据始终一致。

## 二、导入时自动点亮（完整实现仅私有存证）

在导入「服务器详情表」时，系统会在落库的同时完成拓扑推导：按上联记录定位目标交换机、推断端口总数、把对应端口点亮并回填对端设备与线缆，实现「导入即成图」。**该完整实现未在本仓库公开**，仅由私有仓库 `IDC3D-full` 存证；本仓库只公开上面第一项的联动核心逻辑证明子集。
